Agent einrichten

Der Agent ist ein einzelnes Programm. Er liest das Journal (SSH, sudo, su, Sitzungen) und, wenn auditd läuft, ausgeführte Befehle und Änderungen an überwachten Pfaden. Was nicht ankommt, puffert er und schickt es später.

Mit Ansible geht es am einfachsten: Rolle agent/ansible/trailr_agent, sie rechnet den Schlüssel je Host selbst aus und prüft die Prüfsumme gegen den Wert in der Rolle.

{{if .D.Schluessel}}

Auf {{.D.Host}} als root ausführen. Der Schlüssel gilt nur für diesen Host.

curl -fsSo /usr/local/bin/trailr-agent {{.D.Server}}/agent/trailr-agent
echo "<Prüfsumme aus agent/ansible/trailr_agent/defaults/main.yml>  /usr/local/bin/trailr-agent" | sha256sum -c
chmod 755 /usr/local/bin/trailr-agent
useradd --system --no-create-home --shell /usr/sbin/nologin --groups systemd-journal trailr
install -d -m 700 /etc/trailr
umask 077
printf 'TRAILR_SERVER={{.D.Server}}\nTRAILR_HOST={{.D.Host}}\nTRAILR_SCHLUESSEL={{.D.Schluessel}}\n' > /etc/trailr/agent.env

# Befehle und Dateien (optional): auditd mit den Regeln aus dem Repository
apt install -y auditd
cp agent/ansible/trailr_agent/files/audit.rules /etc/audit/rules.d/trailr.rules
augenrules --load

# Dienst
cp agent/ansible/trailr_agent/files/trailr-agent.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now trailr-agent
{{end}}

Die Prüfsumme bitte aus dem Repository nehmen, nicht von diesem Server: sonst prüft der Server sich selbst. Der Agent läuft als eigener Benutzer trailr und darf nur lesen. Ereignisse werden {{.D.Tage}} Tage aufbewahrt.
